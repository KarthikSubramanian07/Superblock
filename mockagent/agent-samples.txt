SUPERBLOCK — AGENT API REFERENCE
Mock server: http://localhost:8000
=================================


── INGESTION AGENT ─────────────────────────────────────────────────────────────

Endpoint : GET /ingestion/status
Input    : (none)

Sample response:
{
  "packets_per_min": 47,
  "sensors_online":  12,
  "last_batch_id":   128,
  "total_tiles":     2791,
  "status":          "active"           // "active" | "idle" | "error"
}

Endpoint : GET /tiles?hour={0–23}
Input    : hour  (integer, 0–23)

[

    "h3_index":  "8b29a1d71911fff",

  ...
]

Endpoint : GET /hotspots
Input    : (none)

── DIAGNOSIS AGENT ──────────────────────────────────────────────────────────────

Endpoint : GET /diagnosis?h3_index={h3_index}
Input    : h3_index  (string, H3 cell ID at resolution 11)

Sample request:
  GET /diagnosis?h3_index=8b29a1d71911fff

Sample response:
{
  "h3_index":           "8b29a1d71911fff",
  "summary":            "High stress at 5th & Grand — Heat exposure dominant",
  "primary_stressor":   "Heat exposure",
  "stressors":          ["heat_exposure", "noise_pollution", "pedestrian_crowding"],
  "als_score":          0.84,
  "severity":           "high",         // "low" | "medium" | "high"
  "recommended_action": "Priority intervention recommended"
}

Error (missing param):
  HTTP 400  { "error": "h3_index required" }

── SIMULATION AGENT ─────────────────────────────────────────────────────────────

Endpoint : POST /simulate
Input    : JSON body

Sample request body:
{
  "h3_index":        "8b29a1d71911fff",
  "intervention_id": "shade_canopy",
  "als_before":      0.84
}

Sample response:
{
  "intervention_id":   "shade_canopy",
  "h3_index":          "8b29a1d71911fff",
  "als_before":        0.84,
  "als_after":         0.60,
  "als_delta":         -0.24,
  "percent_reduction": 29
}

Errors:
  HTTP 400  { "error": "Missing simulation payload" }   — body fields absent
  HTTP 404  { "error": "Intervention not found" }       — unknown intervention_id

── STATUS / FIELD ENUMERATIONS ──────────────────────────────────────────────────

Agent status  : "active" | "processing" | "idle" | "error"
Severity      : "low" | "medium" | "high"
Context       : "stationary" | "walking" | "transit_like"
ALS score     : 0.0–1.0   (< 0.3 green, 0.3–0.5 yellow, 0.5–0.7 orange, ≥ 0.7 red)
